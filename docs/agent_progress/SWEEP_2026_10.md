# October 2026 sweep: build, high block ids, bug fixes

## Resume prompt

> LDFAWE was brought in line with the dev-configurations mod template (buildscript 1784768619,
> RFG 1.4.7, verified-upload release workflow, server smoke test), issues #19 and #20 were fixed, and
> four audits (high block ids; commands/brushes/masks; clipboard/schematic/history; queue/forge/
> lighting) were fixed and merged on master. Read "Open items" below before starting new work.

## What was done

- **Build/CI:** buildscript 1784768619 (RFG 1.4.0 is no longer published), template workflows and
  scripts, `.gitattributes`, buildscript update check disabled, Gradle runs on JDK 21. First unit tests
  (JUnit 5, `./gradlew test`, ~50 tests).
- **#20 undo/redo of ids > 4095:** wide-id history format (`MODE_WIDE_IDS`), recorder resolves the
  `0xFFFF` overflow placeholder, int ids in `MutableBlockChange`; block-bag redo fixed; `/frb`
  summary rewritten. Old `.bd` files still read. Histories recorded before this build already hold
  the placeholder and cannot be repaired.
- **#19 masks/counters:** `BlockMask` on BitSets, `//count`, `//distr`, `#solid`.
- **High ids elsewhere:** FaweCache 65535 slot, BundledBlockData bounds, transforms, patterns, brushes,
  chunk copies, disk clipboard, `.schematic` (`AddBlocksFull`), `.fawe` (auto mode 5), structure files
  (platform names via `BlockStateRegistry`), snapshot `//restore` (REID palette sections).
- **Features (requested by the Terminal City builders):** modded blocks rotate/flip with the
  clipboard (`BlockStateRotator`; falls back to turning facing/axis properties when a mod does not
  override `withRotation`, as CSM does not), `//set -p` / `//replace -p` dry run, `//history [player]
  [world]`, documented no-neighbour-update guarantee (`docs/ASYNC_QUEUE_SYSTEM.md`).
- **Regressions from the March audit, fixed:** `Settings.getLimit` (Math.min → non-op players had zero
  limits), inventory mode charging, `flush()` 10 s cut-off truncating history, back-pressure applying
  queues off-thread, sky-light scan cache, section/chunk ring cache, relighter CAS, `PREVENT_CRASHES`
  default.
- About 60 further bug fixes across commands, brushes, masks, clipboards, schematic I/O, history and
  the queue (see `git log 42cc6fc7..`).

- **Decided with the user:** sqlite-jdbc is shaded in (rollback database, `/frb` and inspect work on
  Forge; see addon.gradle for why it is not relocated), `//clearhistory` deletes the history files, and
  bStats metrics default to off.

- **Follow-ups:** history file numbers never repeat within a run; `//setbiome` is undoable (it was never
  recorded with combine-stages) and biome history keeps ids above 255; pasted entities are removed
  by `//undo` and entities removed by `//cut` come back.

## Verified in-game (dev client with REID + CSM, blocks remapped to ids 4095/5000/6797)

- `//set` + `//undo`/`//redo` restore 4095:2, 5000:3, 6797:2 exactly, tile-entity NBT included.
- `//count`, `//distr`, `//replace <high id>`, `//gmask <high id>`.
- Rotated paste turns CSM signal heads (south → west on a 90° turn) and keeps NBT.
- `.schematic` save/load round-trip with high ids and tile entities.
- `//set -p`, `//replace -p`, `//history`.
- Pasted entities appear with a fresh UUID; 122880-block `//set`/`//undo`/`//redo`, and a new edit after
  an undo followed by `//undo`.

## Open items

- **//lazycut** source removal is undoable but takes a second `//undo`, and only for untransformed
  pastes; it is kept in memory only.
- **Existing configs** written after March keep `PREVENT_CRASHES: true` until edited.
- **Anvil (`/anvil`, MCA) and CFI** still handle only 8-bit ids. Anvil now refuses (and leaves
  untouched) any chunk with Add/Add2 or REID palette sections instead of corrupting it; CFI works
  from vanilla palettes. Both are obsolete and off by default.
